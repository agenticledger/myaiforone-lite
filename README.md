## What is it?

MyAIforOne Lite is a desktop app that runs fully on your own machine. Your conversations never leave your computer.

- 💬 **Chat with AI agents** — Claude-powered agents that can read files, run commands, call APIs
- 🔧 **Your tools, your data** — Connect to your own MCP servers (Slack, Gmail, GitHub, etc.)
- 🧠 **Persistent memory** — Agents remember context across conversations
- ⚡ **Cron jobs & goals** — Agents can run on a schedule autonomously
- 🔑 **Your API key** — Uses your own Anthropic key, billed directly to you

## Requirements

- **macOS 12+** or **Windows 10+**
- **Anthropic API key** — [Get one here](https://console.anthropic.com)
- **Claude CLI** — The app will prompt you to install it on first run

## Getting Started

1. Download the installer for your platform
2. Open it and follow the setup wizard
3. Enter your Anthropic API key
4. Name your first agent
5. Start chatting
